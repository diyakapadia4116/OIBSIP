## 📌 Project Overview

This project builds a Machine Learning model to classify SMS messages as **Spam** or **Ham (Not Spam)**.

The dataset contains thousands of labeled SMS messages. After data cleaning and text preprocessing, TF-IDF vectorization is used to convert text into numerical features, and a Logistic Regression model is trained for classification.

---

## 🚀 Features

* Data cleaning and preprocessing

* TF-IDF Vectorization
* Logistic Regression Classification
* Model evaluation using Accuracy, Precision, Recall, and F1-Score
* Prediction on new SMS messages
