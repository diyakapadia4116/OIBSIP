## 📌 Project Overview

This project aims to predict the selling price of a car using Machine Learning. Various factors such as present price, kilometers driven, fuel type, transmission type, and ownership details are used to estimate the car's selling price.

A Linear Regression model is trained on historical car data to understand the relationship between car features and market value, enabling accurate price predictions.
