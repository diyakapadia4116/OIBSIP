## 📌 Project Overview

This project analyzes unemployment trends in India using Python. The dataset contains unemployment statistics across different states and regions of India during 2020.

The main objective is to understand unemployment patterns, identify the impact of COVID-19 on employment, compare rural and urban unemployment rates, and visualize state-wise unemployment trends through various charts and graphs.

---

## 🚀 Features

* Data cleaning and preprocessing
* Handling missing values
* Date formatting and transformation
* Exploratory Data Analysis (EDA)
* Statistical summary of unemployment data
* Trend analysis using visualizations
* Rural vs Urban unemployment comparison
* State-wise unemployment analysis
* Heatmap visualization for monthly unemployment patterns

---

## 📂 Dataset Information

The dataset contains information such as:

* Region (State)
* Date

* Estimated Employed Population
* Estimated Labour Participation Rate (%)
* Area (Rural/Urban)

## 📊 Analysis Performed

### 1️⃣ Data Cleaning

* Removed rows containing only missing values
* Trimmed unnecessary spaces from text columns
* Converted Date column into proper datetime format
* Renamed columns for consistency

### 2️⃣ Exploratory Data Analysis (EDA)

* Dataset overview
* Shape of dataset
* Missing value analysis
* Descriptive statistics

### 3️⃣ Visualizations Created

#### 📈 Chart 1: Overall Unemployment Rate Over Time

Analyzes the monthly unemployment trend in India and highlights the impact of the COVID-19 lockdown period.

#### 🏘️ Chart 2: Rural vs Urban Unemployment

Compares unemployment trends between rural and urban areas across different months.

#### 📊 Chart 3: Top 10 States with Highest Average Unemployment

Identifies the states with the highest average unemployment rates.

#### 🔥 Chart 4: State-wise Unemployment Heatmap

Visualizes unemployment rates across states and months using color intensity.

---

## 📈 Key Insights

* Unemployment rates showed a significant increase during the COVID-19 lockdown period in 2020.
* Urban areas experienced higher unemployment fluctuations compared to rural areas.
* Certain states consistently reported higher unemployment rates than others.
* Heatmap analysis helps identify periods and regions with severe unemployment challenges.
